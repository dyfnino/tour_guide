## WorkBuddy「更新分支 / 获取分支」失效排查（已定位根因）

**现象**：在 WorkBuddy 里点「更新分支」没有任何反应，提示/结果显示获取不到分支。

**根因**：客户端 Git 集成调用的 `git` 来自系统 PATH，本机 PATH 中的 git 是
`C:\tools\git2.21-64\Git\cmd`（Git **2.21.0**），该版本不支持 `%(worktreepath)` 字段，
导致 `git for-each-ref` 直接失败 → 分支列表解析失败 → 前端拿不到分支。

**关键证据**：
- `~/.workbuddy/logs/renderer.log`（2026-10-13 08:48–09:02，即用户点击的时间段）反复出现：
  `worktreeTask.fetchBranches FAIL ... git for-each-ref failed: fatal: unknown field name: worktreepath`
  以及 `worktreeTask.listLocalBranches FAIL ...` 同样错误。
- 复现：`C:\tools\git2.21-64\Git\cmd\git.exe for-each-ref --format='%(worktreepath)'` → `fatal: unknown field name: worktreepath`。
- 对比：客户端自带 PortableGit `2.55.0`（`D:\softinstalls\workbuddy\resources\vendor\PortableGit\cmd` 与
  `C:\Users\dyf_n\.workbuddy\binaries\PortableGit\versions\1.2.0\cmd`）执行同一命令正常输出分支。
- 客户端进程真实 PATH（见 `~/.workbuddy/logs/sandbox/20261013/sandbox_23072_000.log` 的环境变量转储）中
  **没有** 内置 PortableGit 的 cmd 目录，只有 `C:\tools\git2.21-64\Git\cmd`。
- 客户端只用内置 PortableGit 提供 bash（`CODEBUDDY_CODE_GIT_BASH_PATH`），Git 集成本身走 PATH。

**次生问题**：本仓库 `.git` 约 202MB（size-pack 175MB），SSH fetch 到 GitHub 实测 6.2s；
客户端主进程 RPC 4.5s 判 slow、7.8s 判 VERY SLOW 并 rejected，会让点击表现为「无响应」。

**修复方向**（未执行，待用户确认）：让 PATH 中的 git 变为较新版（≥2.36，推荐客户端自带 2.55 或
新版 Git for Windows），改完必须完全退出并重启 WorkBuddy（PATH 仅进程启动时读取）；
顺带对仓库做 gc 瘦身以缩短 fetch 时间。

## 新增/编辑收货地址：省市区改为三级联动选择（已完成）

**需求**：地址编辑页的省/城市/区县由文本输入改为可选。

**方案**：使用微信原生 `<picker mode="region">`（自带全国省市区数据，无需引入 pca 数据文件）。
- `pages/profile/address/edit/edit.wxml`：省/城市/区县三行各自包一层 `picker mode="region"`，
  统一绑定 `bindchange="onRegionChange"`；未选中时显示「请选择省份/城市/区县」占位。
- `edit.js`：新增 `region` 数据（`['省','市','区']`）；`onRegionChange` 一次回填 form.province/city/district + region；
  编辑回填时仅当三级都有值才写入 `region`（避免无效值导致选择器定位异常）；validate 增加「请选择所在地区」校验；
  提交 payload 对 name/phone/detail 做 trim。
- `edit.wxss`：新增 `.picker/.picker-value/.value-text/.placeholder/.picker-arrow`。

**注意**：三行的 picker 共用同一 handler，`value` 绑定 region，所以从任意一行打开都会定位到当前已选地区。
地址列表页与确认订单页按 `province+city+district+detail` 拼接，字段未变，链路无需改动。
后端 `AddressBase` 中 province/city/district 可为空字符串、detail 必填，payload 形状未变。
